# 两晋与十六国地图数据

2026-10-28：八个关键年304、347、376、394、410、417、431、439均改用 `stage-maps.json` 的完整阶段格局。`key-years.json` 仅保留为早期核心区研究记录，不再注册到页面，也不作为缺图回退。下文2026-10-24、2026-10-26说明为此前两批建设记录。西晋、东晋、北魏、南朝在专题年代范围内直接共享这些数据引用，路由ID按专题保留。

六幅快照为 281、327、366、382、395、409 年，以对应原年图页为底稿；其中四张局部图另补南方和缺口，并明确标记补绘。449 年尾声直接共享已有宋魏全图，不把该图冒充 439 年边界。

- `geometry.json`：原图概括面与有单独依据的补绘面。
- `label-points.json`：面内文本位置；不是都城或考古测量坐标。
- `outlines.json`：移除了图框、附图遮挡边与湖泊边缘的政治轮廓。
- `reconstructed-outlines.json`：补绘产生的外缘，独立用疏点线显示；不描出旧图框接缝。
- `metadata.json`：原年来源、地区性质、都城与周边名称。
- `fill-bands.json`：仅淡化未闭合的外围诸部背景，不再用渐隐掩盖东晋南方或西域的缺口。

可复现输入见 `gis/jin-sixteen-kingdoms`，补绘坐标和出处在 `completion-traces.json`。扫描图保留于使用者本地，不进入项目或网站。附图采用独立经纬网；补绘外围只作区域示意，不沿用其他年份的中原政治边界。

四张补绘图常驻显示图例说明。外围背景不代表统一国家或同等行政控制。详见 `docs/research/2026-09-27-jin-completion-audit.md`。

2026-10-24 新增 `key-years.json`：304、347、376、394、410、417、431、439年核心区域态势，独立依据史事重建，不是同年图集配准图。按各年所选转折完成后的年末状态呈现，色块仅为可考据点及其所在核心区域的地理概括，不绘完整疆界；留白不能解释为无人居住或没有政权。界线均以重建疏点线显示，地图常驻标明“史料重建·核心区域示意”。原六幅配准图与449年尾声保留，输入及核验报告见 `gis/jin-sixteen-kingdoms/key-year-{cores,report}.json`。

2026-10-26 新增 `stage-maps.json`：依439→394→304顺序，将这三个年份升级为完整阶段格局示意。同ID覆盖在 `data/series/jin-sixteen-kingdoms/key-year-snapshots.ts` 完成，原核心区输入保留，其余五幅关键年图继续采用核心区版本；地图快照总数仍为15幅。三幅新图均为独立史料重建，疏点线表示推定接界，淡色诸部仅作地理背景，开放外缘不作为国界。不同年份的图集页只作明确标年的地理参照，不冒充本年原图或精确实控疆界。

439年保留仇池、敦煌沮渠余部及张掖年末争夺；394年单列青州争夺和上邽姜乳据地；304年区分晋名义州郡、张轨晋凉州及汉、成初建区域。来源、局限与验证见 `docs/research/2026-10-26-jin-full-stage-atlases.md`。
