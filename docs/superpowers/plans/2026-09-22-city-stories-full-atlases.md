# 城市、专题内容与全图地图实施计划

> 使用 executing-plans 按任务执行；其要求在可用时采用分工执行。用户已授权自主完成本地 Web，保持已有改动。

**Goal:** 补齐金中都城市格局及今北京联系，依据逐字稿为各专题补充独特内容，并按同年原图展示周边政权。

**Architecture:** 城市与专题内容采用独立、带来源的数据和交互组件，嵌入专题首页；疆域地图保持原年快照，扩充同图政权与地理背景。边界可读的政权绘面；原图仅标名称而无可辨边界者保留带说明的位置标签，不虚构封闭国界。地图背景实体与专题人物/时间线筛选分开。

**Tech Stack:** 现有 Next.js / React / TypeScript / MapLibre / QGIS Python / Vitest / Playwright，不加依赖。

## 约束

- 只做 Web；墓仍预留，不做小红书，不部署、不推送。
- 逐字稿是选题来源，不把清洗稿和主持人推测当作已证实史实。关键空间关系核对考古、文博或研究资料。
- 城市结构示意与今址联系区分；不将未确定的城门位置伪装为精确坐标，不混淆金中都与元明清城址。
- 图集原年与图幅截断必须可见；周边部族、属部不能冒称统一直接管辖国家。扫描只本地参考。
