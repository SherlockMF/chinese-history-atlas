# 金中都与大兴城地图重绘

用户已授权按参考图自主完成；本轮同时覆盖金中都、大兴城，保留现有内容与架构。

1. 补数据：城垣、城门、宫城皇城、道路、两市/水系及后世城址对照。金中都参考国家民委刊载复原图、丰台史话及城门研究；大兴城参考《从中国首都计划史论唐代长安城》图5（PDF第14页）。每个对象关联来源。细界依据复原图概括，不冒充考古测量。
2. 复用 MapLibre：本地历史矢量、独立图层与中文地点标签；现代 OSM 可开关。两城均可只看历史、古今叠加、后世城址对照和只看现代。
3. 地点选择：历史门址/区域可点击，说明时期、功能、今城关系；密集宫殿名称在放大后显示，后世建筑单独呈现。
4. 验证：13门及方位、时期隔离、来源覆盖、图层与选择交互测试；typecheck/lint/build；浏览器分别检查两城全图、现代底图与历史对照、窄屏。

精度边界：地理范围与复原图的相对位置作人工概括；不是经过控制点配准的城墙测绘。大兴里坊与渠线只展示组织形式/流向，不声明每条坊界或河岸已获考古定位。
