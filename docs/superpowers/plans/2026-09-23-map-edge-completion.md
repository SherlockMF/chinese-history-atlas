# 地图边缘完整性修复

目标：清除地图沿原图图框留下的假切口；有补充资料时补出概略形貌，保留来源、时间范围和精度区别。

1. 逐张核对阶段图及五代十国年度母版。对照原图区分历史界、自然海岸、图框闭合、采线偏差。
2. 572、612年西部以可追溯通期图作概略复原；仅补原图外区域，保留各年原图内界，不倒灌晚期征服。
3. 按879年原图修正南诏东缘采线。资料不足处不假称精确本年疆域。
4. 增加几何回归测试，重建派生地图；验证原切口已位于面内部、无重叠、海湖未填色、来源进入读者说明。
5. 相关测试、类型检查、构建与浏览器截图验收；记录逐年审计结果。

实现沿用 Python/Shapely 生成器和现有地图数据接口；不新增依赖，不分发参考图，不改叙事数据。
