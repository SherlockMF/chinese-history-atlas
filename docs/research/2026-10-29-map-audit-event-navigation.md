# 年代地图全量排查与事件导航修复

## 范围与结果

检查当前页面实际使用的52组年代地图、386个政治区域：23幅阶段图和29组五代年段（覆盖907—979年）。包含两晋十六国、南北朝、隋、南诏大理、辽西辽、金、西夏等专题共享地图。没有把目录中未启用的旧版文件计入结果。

`scripts/maps/audit-display-geometry.py --check` 最终结果：经纬度和Web Mercator投影中无无效面、无超过1e-7平方度的重叠、无超过0.005平方度的封闭陆地缺口。检查排除了本地自然湖泊轮廓与原陆地底图未纳入的湖中小岛；这不等于每个历史边界都已考证到城市或村落尺度。

## 根因与处理

| 范围 | 根因 | 修复 |
| --- | --- | --- |
| 410、417 | 北凉、西秦、夏的三个端点不共用，留下0.38349平方度三角区，被外围背景接收 | 复用西秦、夏现有接界的公共节点，重建同年地图；添加三点归属回归 |
| 366、395 | “代及北方诸部”“魏及北方诸部”是混合背景，原先仍整块填色 | 仅保留位置名称，不把合组当作单一政权疆域；有据的主体接界保留 |
| 546、572 | 主体与吐谷浑分别描摹同一界带，裁掉重叠不能消除两线之间的白缝 | 对照本地《历史地图集》同年04-21、04-23原图，使用明确的 `sharedCoreEdge` 引用同一段主体采点，保留原采线用于追溯 |
| 两晋与五代部分地图 | 多边形的接触点未插入对侧边；经纬度直线投影后不再共线。旧六位小数序列化也破坏了细小接界 | 离线补齐既有接触点并校验投影往返；保留GEOS坐标精度。极小残差修复有1e-7平方度硬限制，超限直接报错 |
| 首页地图 | Node与浏览器浮点计算末位不同，SVG标签坐标触发hydration警告 | SVG标签及引线与路径保持一致的小数精度；首屏选择值保持服务端与客户端一致 |

自然水面、不确定外围与有来源的退出地区继续留白。未使用邻近年份疆界填补本年资料空缺。各专题仍复用同年地图资源。

五代输出版本更新为 `fixed-943.6`，避免已加载的旧数据缓存混用；固定943周边名称参考版本不变。

## 导航与播放

- 首页仅列该专题有收录事件的年份（包含持续事件的存续年份）。进入按钮跳转到该年时间线。
- 时间线有同年ready地图或受支持的逐年地图时显示“对应年代地图示意”；没有独立同年图时沿用地图页的阶段选择，并明确标注“参考 X 年地图示意（非本年）”。例如280年时间页跳转281年图，不把281年图改标为280年。
- 按用户后续澄清，时间轴保留“暂无收录”区间；首页和时间页下拉均仅列有事件的年份。点击空白区间或逐年前后浏览时保留当前年份，但不将空年份加入下拉选项。
- 播放按当前轨道筛选后的事件年份递进；空列表禁用，最后一年停止，可以重播。
- 时间线切换采用本地URL更新，消除每一步的服务器导航；使用平滑居中与短淡入，窗口隐藏时暂停，尊重减少动画设置。
