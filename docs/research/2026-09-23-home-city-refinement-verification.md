# 首页总图、都城入口与版面核验

## 本次实现

- `features/home/snapshot-hero-map.tsx`：7 个阶段地图专题首屏复用各自快照的完整原图范围，保留全部区域和周边名称；邻近标签错位并以引线对应原位置。五代十国保留年度总图。
- `features/home/hero.tsx`、`home-page-content.tsx`：将已有快照传入首屏，不增加地图网络请求；展示真实图集年份，缺少对应年度时明确提示。
- `components/layout/site-header.tsx`、`mobile-nav.tsx`、`types/series.ts` 与专题配置：金、北齐北周隋增加“都城”，分别到金中都、大兴城。其他专题不出现空入口。
- `app/globals.css`：页头和首页采用同一个 `site-shell`；页头导航独立居中。`city-overlay-explorer.tsx` 的说明和操作按钮改成可收缩的栅格。
- `data/series/city-plan-details.ts`：依刊载图细化鱼藻池岸线与城内水道转折，移除没有岸线依据的莲花池历史多边形，保留水源地点。`city-overlay-canvas.tsx` 水系线使用圆角连接。

## 水系依据与边界

1. [国家民委：金中都城复原图](https://www.neac.gov.cn/seac/c103391/202211/1159788.shtml)：按图内鱼藻池轮廓及西部水道的弯折关系人工描绘。原图分辨率有限，不是实测坐标。
2. [北京市规划和自然资源委员会：蔡蕃谈北京城河湖演变](https://ghzrzyw.beijing.gov.cn/zhengwuxinxi/zxzt/mcbhdjt/yjnr/202106/t20210624_2420557.html)：核对莲花池、莲花河、宫苑水面与凉水河关系。所附《北京历史地图集》水系图用于关系核对，不能据其比例推出精确岸线。
3. 莲花池历史轮廓不以今日公园湖岸替代。宫城、皇城、隋大兴城规则里坊继续采用文献复原的直线组织，不为增加复杂度而编造折点。

- 修改的 TypeScript / TSX 文件 ESLint 通过；`npm run typecheck` 通过；最终 `npm run build` 通过，53 个静态页面完成。

- 浏览器早期后台页截图超时；重新接入现有前台站点标签后完成截图核验。最初发现部分旧检查标签保留了 1500 像素的模拟视口，而窗口外宽为 1440；当前检查页已调回与窗口内容区相符的 1424 × 763。

仍然是有来源的概略复原，不是完成考古控制点配准的城市测绘图。当前地图精度不支持寻找具体墙基或古湖岸。
