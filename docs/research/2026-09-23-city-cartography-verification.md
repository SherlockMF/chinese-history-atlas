# 金中都、大兴城重绘与验收

## 本轮变更

- `data/series/city-plan-details.ts`：按参考图和研究资料绘制城垣、宫城皇城、城门、道路、水系与后世城址；每个历史地点均关联出处。
- `data/series/city-overlays.ts`：补来源、时期差异与精度说明。
- `features/series/city-overlay-canvas.tsx`、`city-overlay-explorer.tsx`、`app/globals.css`：九类可切换图层、历史门名、地点索引、透明度、宫城放大、全城复位、现代地点定位。
- `features/series/city-modern-style.ts`、`public/maps/cities/`、`scripts/maps/prepare-city-basemaps.mjs`：本地现代矢量底图与可复现准备脚本；180个 MVT，约15 MB，来源与许可见目录 README / manifest。
- 四个城市地图测试文件覆盖数据、交互、地图生命周期和本地资产。

## 主要依据与处理

1. 金中都：国家民委2022年文章中的《金中都城复原图》（已下载阅图）、丰台史话的中轴礼仪序列、十三门研究。北四门，其余三面各三门；后增光泰门单独说明。皇城、宫城、宫门、殿宇、鱼藻池、入城水流及南水关均可辨认。
2. 古今北京：参考用户提供的金中都—明清城址对照图。绿色独立表达明清内城、外城和城门；不是元大都轮廓，现代故宫也不当作金中都宫城。
3. 隋大兴：阅《从中国首都计划史论唐代长安城》PDF第14页图5，以其宫城皇城、两市、城门与里坊比例重绘，保留利人市、都会市、大兴门等隋代名称。
4. 隋初南界：结合中国社科院考古所2023年度田野工作报告，说明安化门早期水渠与晚期唐代门址；外郭采用规划虚线，不声称隋初城墙已全部建成。
5. 地理精度：人工概括和定位，尚非控制点配准的考古测绘数据。宫殿轮廓、坊界、水岸表达复原关系，不能用于寻找墙基或导航。数据和界面均保留该说明。

全部原文入口已放在页面的“复原依据与精度说明”和地点详情中。

## 现代底图根因与修复

原 OSM 栅格请求出现 `x-blocked: Access denied`；改接公开 OpenFreeMap 后，浏览器请求仍出现 `net::ERR_CONNECTION_CLOSED`，而本机下载正常。因此最终采用 OpenFreeMap 允许自行托管的开放 MVT 数据，按两座城周边范围保存版本快照。本地提供字形，中文采用系统字体，不代理 OSM 官方受限栅格服务。

最终浏览器中北京、西安现代街道、中文地名、水面与道路均正常显示；西安验收无失败资源请求、无 pageerror、无底图失败提示。覆盖范围外不提供全球现代底图。
