# 金末七篇独立复核

2026-10-11。J08、J10—J15七篇271行由根代理逐段对读原逐字稿、正文与相关史源；未回听音频。

- 野狐岭：1211金史承裕与元史九斤的纪年差异分开，不把役戍七十五万当作同一场战役实兵数。
- 中都：1213河北十一城未下、承晖末书朱喜二字倒写、从良致家书及师姑遇害补回；元史58链接修为卷058。1267营新城与1272大都分开，未核赏金保留部分覆盖。
- 高琪：杀己妻及婢的对象纠正，1219／1220年表分别说明；木华黎1217受任、1223死亡不并成1219。
- 三峰山：三路会师、李昌国、拒使、蒲阿与合达终局逐项定位；双方数量与死期按版本分开。
- 拖雷监国：1227—1229与宿卫万人、楚材定策及察合台拥戴分别叙述；巫水传说与元史病愈、卒日不硬合一个确定死因。
- 三宰相：白撒竹具渡河、饥死狱中，官奴偷袭及照碧堂斫杀逐项补入；归德军纪围墙用于约束军士，不改成围困皇帝。
- 蔡州：末帝承麟为传位后的不同终局，哀宗即位哭笑、衣麻与杖责，军属租田、贾中材评价等均据实际段落处理；不编一小时在位。

相关出处读《金史》《元史》及蒙古史料对应章节，正文分开史实、异载和文学流传；不以登记数量宣称所有原段完整覆盖。
